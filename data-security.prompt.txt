# Data Security Platform - Prompt Specification
## Tech Stack Alignment
MUST USE APPROVED STACK:
- Backend: Node.js 18, Express.js, PostgreSQL 16, Redis 7, RabbitMQ 3, JWT, bcryptjs
- Frontend: React 18, React Router 6, Bootstrap 5, Chart.js (dashboard)
- Infra: Docker (node:18-alpine), Docker Compose, Kubernetes, Nginx Alpine
- Security: OWASP API Top 10, Helmet, Rate Limiting, JWT Auth via API Gateway

## 1. Component Overview
Microservice for data discovery, classification, loss prevention (DLP), and encryption management across multi-tenant environments with real-time monitoring of sensitive data flows and automated policy enforcement.

## 2. Core Requirements
- Data discovery and classification (PII, PHI, PCI, intellectual property) using pattern matching
- Data Loss Prevention (DLP) policies with content inspection
- Encryption key management integration (AWS KMS, Azure Key Vault, HashiCorp Vault)
- Data flow mapping and monitoring across cloud and on-prem environments
- Automated policy enforcement (block, alert, quarantine) for policy violations
- Integration with CSPM for cloud storage security (S3, Azure Blob, GCP Storage)
- Redis caching for classification rules and policy decisions
- RabbitMQ event publishing for DLP violations, policy breaches

## 4. Database Schema (PostgreSQL)
```sql
CREATE TABLE data_assets (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  name VARCHAR(255) NOT NULL,
  asset_type VARCHAR(50) NOT NULL, -- database, file_share, cloud_storage, api
  location VARCHAR(255), -- s3://bucket, /mnt/share, db_connection_string
  classification VARCHAR(50), -- public, internal, confidential, restricted
  data_types TEXT[] DEFAULT '{}', -- PII, PHI, PCI, IP
  encryption_status VARCHAR(20) DEFAULT 'unknown', -- encrypted, unencrypted, partial
  owner VARCHAR(255),
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE dlp_policies (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  name VARCHAR(255) NOT NULL,
  rules JSONB NOT NULL, -- pattern matching, content inspection rules
  action VARCHAR(20) DEFAULT 'alert', -- alert, block, quarantine
  enabled BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE data_violations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  asset_id UUID REFERENCES data_assets(id),
  policy_id UUID REFERENCES dlp_policies(id),
  violation_type VARCHAR(100),
  severity VARCHAR(20),
  content_excerpt TEXT, -- masked/partial content
  action_taken VARCHAR(20),
  status VARCHAR(20) DEFAULT 'open', -- open, investigating, resolved
  created_at TIMESTAMP DEFAULT NOW(),
  resolved_at TIMESTAMP
);

CREATE TABLE encryption_keys (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  key_id VARCHAR(255) NOT NULL,
  key_provider VARCHAR(50), -- aws_kms, azure_keyvault, hashicorp_vault
  algorithm VARCHAR(50),
  status VARCHAR(20) DEFAULT 'active',
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_data_tenant ON data_assets(tenant_id);
```

## 5. Service Integrations
- Redis: Cache classification results, DLP policy decisions, encryption status
- RabbitMQ: Publish to `data-security-events` queue (violation.detected, policy.breached, encryption.failed)
- API Gateway: All endpoints routed through `/api/data-security/*`
- CSPM Service: Sync cloud storage security findings
- GRC Service: Map data risks to risk register
- IAM Service: Validate tenant_id from JWT token

## 6. Security Requirements
- All endpoints protected by API Gateway OWASP policies
- Tenant isolation: queries filtered by JWT tenant_id
- Encrypt sensitive data at rest and in transit (TLS 1.3)
- Audit logging: all data access and policy changes logged to `request_logs`
- Mask sensitive content in violation logs (show only partial/obfuscated data)
- mTLS for service-to-service communication
- Encryption keys stored in external vault, never in database

## 7. Deployment
### Dockerfile
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
EXPOSE 3012
HEALTHCHECK --interval=30s --timeout=10s --retries=3 \
  CMD node -e "require('http').get('http://localhost:3012/health', (r) => {process.exit(r.statusCode === 200 ? 0 : 1)})"
CMD ["node", "server.js"]
```

### Docker Compose Block
```yaml
data-security:
  platform: linux/amd64
  build:
    context: ./data-security-service
    dockerfile: Dockerfile
  container_name: cybersec-data-security
  ports:
    - "3012:3012"
  environment:
    NODE_ENV: production
    PORT: 3012
    DATABASE_URL: postgresql://cybersec:securepassword@postgres:5432/cybersec_platform
    REDIS_URL: redis://redis:6379
    RABBITMQ_URL: amqp://cybersec:securepassword@rabbitmq:5672
    GRC_SERVICE_URL: http://grc:3007
  depends_on:
    postgres:
      condition: service_healthy
    redis:
      condition: service_healthy
  healthcheck:
    test: ["CMD", "node", "-e", "require('http').get('http://localhost:3012/health', (r) => {process.exit(r.statusCode === 200 ? 0 : 1)})"]
    interval: 30s
    timeout: 10s
    retries: 3
  networks:
    - cybersec-network
```
