# NGFW Platform (Next-Generation Firewall) - Master Prompt Specification
## Tech Stack Alignment
MUST USE APPROVED STACK:
- Backend: Node.js 18, Express.js, PostgreSQL 16, Redis 7, RabbitMQ 3, JWT, bcryptjs
- Frontend: React 18, React Router 6, Bootstrap 5, Chart.js (dashboard)
- Infra: Docker (node:18-alpine), Docker Compose, Kubernetes, Nginx Alpine
- Security: OWASP API Top 10, Helmet, Rate Limiting, JWT Auth via API Gateway

## 1. Component Overview
Next-Generation Firewall microservice providing deep packet inspection (DPI), application-aware filtering, IPS/IDS integration, geo-blocking, and real-time network threat prevention with integration to Threat Intelligence and SOAR services.

## 2. Core Requirements
- Stateful packet inspection with layer 7 (application layer) filtering
- IPS/IDS integration (Suricata rules integration)
- Application identification and control (detect/block specific apps)
- Geo-blocking with country-level filtering (MaxMind DB integration)
- NAT, port forwarding, and VPN tunnel management
- Real-time traffic monitoring and logging to Data Lake
- Integration with Threat Intel for malicious IP/domain blocking
- Redis caching for active rules, IP reputation, traffic counters
- RabbitMQ event publishing for blocked traffic, policy violations, DDoS detection

## 4. Database Schema (PostgreSQL)
```sql
CREATE TABLE ngfw_rules (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  name VARCHAR(255) NOT NULL,
  action VARCHAR(20) NOT NULL, -- allow, deny, log
  source_ip CIDR[],
  dest_ip CIDR[],
  source_port INT[],
  dest_port INT[],
  protocol VARCHAR(20), -- tcp, udp, icmp, any
  application VARCHAR(100), -- http, ssh, dns, custom
  enabled BOOLEAN DEFAULT true,
  priority INT DEFAULT 100,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE ngfw_geo_blocks (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  country_code CHAR(2) NOT NULL, -- ISO 3166-1 alpha-2
  action VARCHAR(20) DEFAULT 'deny', -- deny, alert
  enabled BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE ngfw_traffic_logs (
  id BIGSERIAL PRIMARY KEY,
  tenant_id UUID REFERENCES tenants(id),
  source_ip INET NOT NULL,
  dest_ip INET NOT NULL,
  source_port INT,
  dest_port INT,
  protocol VARCHAR(20),
  action VARCHAR(20),
  rule_id UUID REFERENCES ngfw_rules(id),
  timestamp TIMESTAMP DEFAULT NOW(),
  INDEX (tenant_id, timestamp DESC)
);

CREATE TABLE ngfw_ips_alerts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  signature_id VARCHAR(100), -- Suricata SID
  severity VARCHAR(20),
  source_ip INET,
  dest_ip INET,
  description TEXT,
  action_taken VARCHAR(50),
  timestamp TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_ngfw_rules_tenant ON ngfw_rules(tenant_id);
```

## 5. Service Integrations
- Redis: Cache active rules, geo-IP lookups, traffic counters (TTL 1h)
- RabbitMQ: Publish to `ngfw-events` queue (traffic.blocked, ips.alert, ddos.detected, geo.block_triggered)
- API Gateway: All endpoints routed through `/api/ngfw/*`
- Threat Intel Service: Pull malicious IPs for automatic blocking
- SOAR Service: Trigger playbooks for IPS alerts, DDoS mitigation
- Data Lake: Send traffic logs for long-term storage and analysis
- IAM Service: Validate tenant_id from JWT token

## 6. Security Requirements
- All endpoints protected by API Gateway OWASP policies
- Tenant isolation: queries filtered by JWT tenant_id
- Encrypt sensitive rule configurations at rest
- Audit logging: all rule changes logged to `request_logs`
- Rate limiting on API to prevent rule flooding
- mTLS for service-to-service communication
- Default-deny policy: implicit deny all unless explicitly allowed

## 7. Deployment
### Dockerfile
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
EXPOSE 3002
HEALTHCHECK --interval=30s --timeout=10s --retries=3 \
  CMD node -e "require('http').get('http://localhost:3002/health', (r) => {process.exit(r.statusCode === 200 ? 0 : 1)})"
CMD ["node", "server.js"]
```

### Docker Compose Block (matches existing ngfw-service)
```yaml

  build:
```
