# Cloud Security Posture Management (CSPM) - Prompt Specification
## Tech Stack Alignment
MUST USE APPROVED STACK:
- Backend: Node.js 18, Express.js, PostgreSQL 16, Redis 7, RabbitMQ 3, JWT, bcryptjs
- Frontend: React 18, React Router 6, Bootstrap 5, Chart.js, React ChartJS 2 (dashboard)
- Infra: Docker (node:18-alpine), Docker Compose, Kubernetes, Nginx Alpine
- Security: OWASP API Top 10, Helmet, Rate Limiting, JWT Auth via API Gateway

## 1. Component Overview
Microservice for continuous cloud security posture assessment across AWS, Azure, and GCP with automated compliance checks against CIS benchmarks, NIST, and custom policies, integrated with the platform's GRC and Vulnerability Scanner services.

## 2. Core Requirements
- Multi-cloud connector framework (AWS Config, Azure Security Center, GCP Security Command Center integrations)
- CIS Benchmark v8 compliance scanning with automated checks
- Custom policy engine for cloud-specific security rules
- Misconfiguration detection (open S3 buckets, unencrypted databases, open security groups)
- Compliance score tracking with Redis caching for real-time dashboards
- Remediation workflow integration with SOAR service
- RabbitMQ event publishing for critical misconfigurations, compliance failures

## 3. API Endpoints (routed via API Gateway: /api/cspm/*)
| Method | Endpoint | Description | Auth |
|--------|----------|-------------|------|
| GET | /health | Health check | None |
| GET | /api/cspm/accounts | List connected cloud accounts | JWT/API Key |
| POST | /api/cspm/accounts | Register new cloud account | Admin JWT |
| GET | /api/cspm/findings | List security findings | JWT/API Key |
| GET | /api/cspm/findings/:id | Get finding details | JWT/API Key |
| PUT | /api/cspm/findings/:id | Update finding status | JWT/API Key |

| GET | /api/cspm/compliance | Get compliance score/report | JWT/API Key |
| GET | /api/cspm/policies | List CSPM policies | JWT/API Key |

## 4. Database Schema (PostgreSQL)
```sql
CREATE TABLE cspm_accounts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  cloud_provider VARCHAR(20) NOT NULL, -- aws, azure, gcp
  account_id VARCHAR(255) NOT NULL,
  account_name VARCHAR(255),
  credentials_encrypted TEXT NOT NULL, -- encrypted API keys/Service Principal
  status VARCHAR(20) DEFAULT 'active', -- active, error, disabled
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE cspm_findings (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  account_id UUID REFERENCES cspm_accounts(id),
  finding_type VARCHAR(100) NOT NULL, -- misconfiguration, compliance_violation
  severity VARCHAR(20) NOT NULL, -- low, medium, high, critical
  resource_type VARCHAR(100), -- s3_bucket, ec2_instance, azure_vm
  resource_id VARCHAR(255),
  title VARCHAR(255) NOT NULL,
  description TEXT,
  compliance_standard VARCHAR(50), -- CIS, NIST, PCI-DSS
  status VARCHAR(20) DEFAULT 'open', -- open, in_progress, resolved, false_positive
  remediation TEXT,
  discovered_at TIMESTAMP DEFAULT NOW(),
  resolved_at TIMESTAMP
);

CREATE TABLE cspm_policies (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  name VARCHAR(255) NOT NULL,
  cloud_provider VARCHAR(20),
  policy_type VARCHAR(50), -- cis_benchmark, custom_rule
  rules JSONB NOT NULL,
  enabled BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE cspm_compliance_scores (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  account_id UUID REFERENCES cspm_accounts(id),
  standard VARCHAR(50), -- CIS_v8, NIST_800-53
  score DECIMAL(5,2), -- percentage 0-100
  checked_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_cspm_tenant ON cspm_findings(tenant_id);
```

## 5. Service Integrations
- Redis: Cache compliance scores, findings summary, policy results
- RabbitMQ: Publish to `cspm-events` queue (finding.discovered, compliance.violation, remediation.required)
- API Gateway: All endpoints routed through `/api/cspm/*`
- GRC Service: Sync compliance scores, map findings to risk register
- SOAR Service: Trigger remediation playbooks for critical findings
- Vulnerability Scanner: Correlate cloud resource vulns with CSPM findings
- IAM Service: Validate tenant_id from JWT token

## 6. Security Requirements
- All endpoints protected by API Gateway OWASP policies
- Tenant isolation: queries filtered by JWT tenant_id
- Encrypt cloud credentials at rest (AES-256)
- Audit logging: scan results and policy changes logged to `request_logs`
- mTLS for service-to-service communication
- Read-only cloud credentials with minimal permissions

## 7. Deployment
### Dockerfile
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
EXPOSE 3011
HEALTHCHECK --interval=30s --timeout=10s --retries=3 \
  CMD node -e "require('http').get('http://localhost:3011/health', (r) => {process.exit(r.statusCode === 200 ? 0 : 1)})"
CMD ["node", "server.js"]
```

### Docker Compose Block
```yaml
cspm:
  platform: linux/amd64
  build:
    context: ./cspm-service
    dockerfile: Dockerfile
  container_name: cybersec-cspm
  ports:
    - "3011:3011"
  environment:
    NODE_ENV: production
    PORT: 3011
    DATABASE_URL: postgresql://cybersec:securepassword@postgres:5432/cybersec_platform
    REDIS_URL: redis://redis:6379
    RABBITMQ_URL: amqp://cybersec:securepassword@rabbitmq:5672
    GRC_SERVICE_URL: http://grc:3007
    SOAR_SERVICE_URL: http://siem-soar:3003
  depends_on:
    postgres:
      condition: service_healthy
    redis:
      condition: service_healthy
  healthcheck:
    test: ["CMD", "node", "-e", "require('http').get('http://localhost:3011/health', (r) => {process.exit(r.statusCode === 200 ? 0 : 1)})"]
    interval: 30s
    timeout: 10s
    retries: 3
  networks:
    - cybersec-network
```
