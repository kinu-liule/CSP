# Password Manager Platform - Master Prompt Specification
## Tech Stack Alignment
MUST USE APPROVED STACK:
- Backend: Node.js 18, Express.js, PostgreSQL 16, Redis 7, RabbitMQ 3, JWT, bcryptjs
- Frontend: React 18, React Router 6, Bootstrap 5, Chart.js (password usage dashboard)
- Infra: Docker (node:18-alpine), Docker Compose, Kubernetes, Nginx Alpine
- Security: OWASP API Top 10, Helmet, Rate Limiting, JWT Auth via API Gateway

## 1. Component Overview
Password Manager Platform for secure storage, sharing, and rotation of credentials, integrating with IAM for user authentication, audit logging, and compliance reporting.

## 2. Core Requirements
- Secure password storage with AES-256 encryption at rest
- Password sharing with expiration, access controls, and audit trails
- Automated password rotation policies per application/tenant
- Integration with IAM service for user identity verification
- Audit logging for all password access/modification events
- Compliance reporting (PCI-DSS, HIPAA, SOC2)
- Redis caching for frequently accessed credentials (TTL 1h)

## 3. API Endpoints (routed via API Gateway: /api/password-manager/*)
| Method | Endpoint | Description | Auth |
|--------|----------|-------------|------|
| GET | /health | Health check | None |
| GET | /api/password-manager/passwords | List passwords | JWT |
| POST | /api/password-manager/passwords | Create new password entry | JWT |
| GET | /api/password-manager/passwords/:id | Get password details | JWT |
| PUT | /api/password-manager/passwords/:id | Update password | JWT |
| DELETE | /api/password-manager/passwords/:id | Delete password | JWT |
| POST | /api/password-manager/share | Share password with user | JWT |
| GET | /api/password-manager/shared | List shared passwords | JWT |
| GET | /api/password-manager/audit-logs | Get audit logs | Admin JWT |
| POST | /api/password-manager/rotate | Trigger password rotation | Admin JWT |

## 4. Database Schema (PostgreSQL)
```sql
CREATE TABLE password_entries (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  user_id UUID REFERENCES users(id),
  name VARCHAR(255) NOT NULL,
  username VARCHAR(255),
  password_encrypted TEXT NOT NULL,
  url VARCHAR(500),
  category VARCHAR(100),
  notes TEXT,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE shared_passwords (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  password_id UUID REFERENCES password_entries(id),
  shared_with_user_id UUID REFERENCES users(id),
  expires_at TIMESTAMP,
  access_count INT DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE rotation_policies (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  application_name VARCHAR(255),
  rotation_interval_days INT DEFAULT 90,
  enabled BOOLEAN DEFAULT true,
  last_rotation TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE password_audit_logs (
  id BIGSERIAL PRIMARY KEY,
  tenant_id UUID REFERENCES tenants(id),
  user_id UUID REFERENCES users(id),
  action VARCHAR(50),
  password_id UUID REFERENCES password_entries(id),
  ip_address INET,
  timestamp TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_passwords_tenant ON password_entries(tenant_id);
```

## 5. Service Integrations
- Redis: Cache decrypted passwords (TTL 1h), rotation policy status
- RabbitMQ: Publish to `password-manager-events` queue
- API Gateway: All endpoints routed through `/api/password-manager/*`
- IAM Service: Validate JWT tokens, sync user identities
- SIEM Service: Send audit logs for compliance monitoring
- GRC Service: Report on password policy compliance

## 6. Security Requirements
- AES-256 encryption for stored passwords
- Tenant isolation: queries filtered by JWT tenant_id
- Audit logging for all access/modification events
- Rate limiting on password retrieval (max 10/minute per user)
- mTLS for service-to-service communication
- Password strength enforcement (min 12 chars, complexity)

## 7. Deployment
### Dockerfile
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
EXPOSE 3016
HEALTHCHECK --interval=30s --timeout=10s --retries=3 \
  CMD node -e "require('http').get('http://localhost:3016/health', (r) => {process.exit(r.statusCode === 200 ? 0 : 1)})"
CMD ["node", "server.js"]
```

### Docker Compose Block
```yaml
password-manager:
  platform: linux/amd64
  build:
    context: ./password-manager-service
    dockerfile: Dockerfile
  container_name: cybersec-password-mgr
  ports:
    - "3016:3016"
  environment:
    NODE_ENV: production
    PORT: 3016
    DATABASE_URL: postgresql://cybersec:securepassword@postgres:5432/cybersec_platform
    REDIS_URL: redis://redis:6379
    RABBITMQ_URL: amqp://cybersec:securepassword@rabbitmq:5672
    IAM_SERVICE_URL: http://iam:3008
  depends_on:
    postgres:
      condition: service_healthy
    redis:
      condition: service_healthy
  healthcheck:
    test: ["CMD", "node", "-e", "require('http').get('http://localhost:3016/health', (r) => {process.exit(r.statusCode === 200 ? 0 : 1)})"]
    interval: 30s
    timeout: 10s
    retries: 3
  networks:
    - cybersec-network
```
