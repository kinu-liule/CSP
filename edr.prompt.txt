# Endpoint Detection & Response (EDR) Platform - Prompt Specification
## Tech Stack Alignment
MUST USE APPROVED STACK:
- Backend: Node.js 18, Express.js, PostgreSQL 16, Redis 7, RabbitMQ 3, JWT, bcryptjs
- Frontend: React 18, React Router 6, Bootstrap 5, Chart.js (dashboard)
- Infra: Docker (node:18-alpine), Docker Compose, Kubernetes, Nginx Alpine
- Security: OWASP API Top 10, Helmet, Rate Limiting, JWT Auth via API Gateway

## 1. Component Overview
Microservice for endpoint monitoring, threat detection, and automated response across multi-tenant environments with real-time telemetry collection, behavioral analysis, and integration with SOAR for incident response.

## 2. Core Requirements
- Endpoint agent management (deploy, configure, monitor agents on Windows/Linux/Mac)
- Real-time telemetry collection (process execution, file changes, network connections, registry modifications)
- Behavioral analysis and anomaly detection using Risk Engine (Python/FastAPI)
- Threat detection rules engine (YARA, Sigma rules)
- Automated response actions (isolate endpoint, kill process, delete file)
- Integration with Threat Intelligence for IOC (Indicators of Compromise) matching
- Redis caching for agent status, threat intel, and recent telemetry
- RabbitMQ event publishing for detections, agent alerts, response actions

## 3. API Endpoints (routed via API Gateway: /api/edr/*)
| Method | Endpoint | Description | Auth |
|--------|----------|-------------|------|
| GET | /health | Health check | None |
| GET | /api/edr/agents | List endpoint agents | JWT/API Key |
| POST | /api/edr/agents | Register new agent | Admin JWT |
| GET | /api/edr/agents/:id | Get agent details | JWT/API Key |
| PUT | /api/edr/agents/:id | Update agent config | Admin JWT |
| DELETE | /api/edr/agents/:id | Decommission agent | Admin JWT |
| GET | /api/edr/telemetry | Get endpoint telemetry | JWT/API Key |
| GET | /api/edr/detections | List threat detections | JWT/API Key |
| POST | /api/edr/response | Trigger response action | Admin JWT |
| GET | /api/edr/metrics | Get EDR metrics | JWT/API Key |

## 4. Database Schema (PostgreSQL)
```sql
CREATE TABLE edr_agents (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  hostname VARCHAR(255) NOT NULL,
  ip_address INET,
  os VARCHAR(100),
  os_version VARCHAR(100),
  agent_version VARCHAR(50),
  status VARCHAR(20) DEFAULT 'active', -- active, offline, isolated
  last_checkin TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE edr_telemetry (
  id BIGSERIAL PRIMARY KEY,
  tenant_id UUID REFERENCES tenants(id),
  agent_id UUID REFERENCES edr_agents(id),
  event_type VARCHAR(50), -- process_exec, file_modify, network_connect
  event_data JSONB NOT NULL,
  timestamp TIMESTAMP DEFAULT NOW()
);

CREATE TABLE edr_detections (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  agent_id UUID REFERENCES edr_agents(id),
  detection_type VARCHAR(100), -- malware, behavior_anomaly, ioc_match
  severity VARCHAR(20),
  rule_id VARCHAR(255),
  event_data JSONB,
  response_action VARCHAR(50), -- isolate, kill_process, alert_only
  status VARCHAR(20) DEFAULT 'open', -- open, investigating, resolved
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE edr_response_actions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  agent_id UUID REFERENCES edr_agents(id),
  detection_id UUID REFERENCES edr_detections(id),
  action_type VARCHAR(50), -- isolate_endpoint, kill_process, delete_file
  status VARCHAR(20), -- pending, completed, failed
  result JSONB,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_edr_tenant ON edr_agents(tenant_id);
CREATE INDEX idx_edr_telemetry_agent ON edr_telemetry(agent_id, timestamp);
```

## 5. Service Integrations
- Redis: Cache agent status, threat intel IOCs, recent telemetry (TTL 1h)
- RabbitMQ: Publish to `edr-events` queue (detection.created, agent.offline, response.action_required)
- API Gateway: All endpoints routed through `/api/edr/*`
- Risk Engine: Send telemetry for behavioral analysis (HTTP to `risk-engine:8000`)
- Threat Intel Service: Pull IOCs for real-time matching
- SOAR Service: Trigger incident response playbooks
- IAM Service: Validate tenant_id from JWT token

## 6. Security Requirements
- All endpoints protected by API Gateway OWASP policies
- Tenant isolation: queries filtered by JWT tenant_id
- Encrypt sensitive telemetry data at rest
- Audit logging: agent actions and response actions logged to `request_logs`
- mTLS for agent-to-server communication
- Agent authentication via mutual TLS or signed tokens

## 7. Deployment
### Dockerfile
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
EXPOSE 3015
HEALTHCHECK --interval=30s --timeout=10s --retries=3 \
  CMD node -e "require('http').get('http://localhost:3015/health', (r) => {process.exit(r.statusCode === 200 ? 0 : 1)})"
CMD ["node", "server.js"]
```

### Docker Compose Block
```yaml
edr:
  platform: linux/amd64
  build:
    context: ./edr-service
    dockerfile: Dockerfile
  container_name: cybersec-edr
  ports:
    - "3015:3015"
  environment:
    NODE_ENV: production
    PORT: 3015
    DATABASE_URL: postgresql://cybersec:securepassword@postgres:5432/cybersec_platform
    REDIS_URL: redis://redis:6379
    RABBITMQ_URL: amqp://cybersec:securepassword@rabbitmq:5672

```
